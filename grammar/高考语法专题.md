## 专题一：时态与语态

### 核心口诀
- **一般现在表习惯，一般过去过去事**
- **现在完成到现在，过去完成更早前**
- **进行时态动作中，被动语态被人做**

### 时态一览表

| 时态 | 结构 | 用法 | 时间标志词 |
|------|------|------|----------|
| 一般现在时 | do/does | 习惯、真理 | always, usually, often |
| 一般过去时 | did | 过去的事 | yesterday, last week, ago |
| 一般将来时 | will do / be going to | 将来 | tomorrow, next week |
| 现在进行时 | am/is/are doing | 正在进行 | now, at the moment |
| 过去进行时 | was/were doing | 过去某时正在 | at that time, when |
| 现在完成时 | have/has done | 从过去到现在 | already, yet, since, for |
| 过去完成时 | had done | 过去的过去 | by the time, before |
| 将来完成时 | will have done | 将来某时前完成 | by + 将来时间 |

### 被动语态

**结构**：be + 过去分词

| 时态 | 被动语态结构 |
|------|-------------|
| 一般现在时 | am/is/are + done |
| 一般过去时 | was/were + done |
| 一般将来时 | will be + done |
| 现在完成时 | have/has been + done |
| 过去完成时 | had been + done |
| 情态动词 | can/should/must + be + done |

## 专题二：定语从句

### 核心口诀
- **缺主宾用关代，不缺成分用关副**
- **先行词是人用who/whom/that/whose**
- **先行词是物用which/that/whose**

### 关系代词 vs 关系副词

| 类型 | 关系词 | 先行词 | 在从句中作用 |
|------|--------|--------|--------------|
| 关系代词 | who/whom/whose/which/that | 人/物 | 主语/宾语/定语 |
| 关系副词 | when/where/why | 时间/地点/原因 | 状语 |

### 只用that的情况
1. 先行词是all, everything, anything, nothing等
2. 先行词被only, very, the same等修饰
3. 先行词被序数词或最高级修饰
4. 先行词既有人又有物
5. 主句是以who, which开头的特殊疑问句

### 不用that的情况
1. 非限制性定语从句
2. 介词后

## 专题三：名词性从句

### 四种名词性从句

| 类型 | 位置 | 例句 |
|------|------|------|
| 主语从句 | 句首/It形式主语 | What he said is true. |
| 宾语从句 | 动词/介词后 | I believe that he is honest. |
| 表语从句 | 系动词后 | The fact is that we have lost. |
| 同位语从句 | 抽象名词后 | The news that he won surprised us. |

### 引导词选择

| 引导词 | 用法 |
|--------|------|
| that | 无意义，不作成分 |
| what | 意为"什么/...的东西"，作主宾表 |
| whether/if | 意为"是否" |
| who/whom/whose/which | 意为"谁/谁的/哪个" |
| when/where/why/how | 意为"何时/何地/为何/如何" |

### 同位语从句 vs 定语从句

| | 同位语从句 | 定语从句 |
|---|----------|---------|
| that | 不作成分 | 作主语或宾语 |
| 功能 | 解释抽象名词内容 | 修饰限定先行词 |
| 能否换成which | 不能 | 能（指物时） |

## 专题四：非谓语动词

### 三种形式

| 形式 | 结构 | 用法 |
|------|------|------|
| 不定式 | to do | 表目的、将来 |
| 动名词 | doing | 表习惯、已做 |
| 分词 | doing(主动)/done(被动) | 表状态、伴随 |

### 核心口诀
- **动名词表习惯，不定式表目的**
- **现在分词表主动，过去分词表被动**
- **非谓语的逻辑主语是句子主语**

### 常见动词搭配

**只接不定式**：
want, wish, hope, expect, decide, agree, refuse, promise, plan, manage, fail, pretend, afford

**只接动名词**：
enjoy, practice, avoid, finish, mind, consider, suggest, keep, imagine, risk, appreciate

**两者皆可（意义相同）**：
begin, start, continue, like, love, hate, prefer

**两者皆可（意义不同）**：
- remember/forget to do（记得/忘记要做）vs doing（记得/忘记做过）
- stop to do（停下来去做）vs doing（停止做）
- try to do（努力做）vs doing（尝试做）

## 专题五：虚拟语气

### 核心口诀
- **与现在相反用过去**
- **与过去相反用完成**
- **与将来相反should/were to do**

### If虚拟条件句

| 时间 | 条件句 | 主句 |
|------|--------|------|
| 与现在相反 | If + did/were | would/could/might/should + do |
| 与过去相反 | If + had done | would/could/might/should + have done |
| 与将来相反 | If + did/were/should do/were to do | would/could/might/should + do |

### 特殊虚拟情况

**wish后**：
- 与现在相反：wish + did/were
- 与过去相反：wish + had done
- 与将来相反：wish + would/could + do

**suggest/insist/demand等后的宾语从句**：
- should + do（should可省略）

**It's (high) time that...**
- did / should do

## 专题六：特殊句式

### 1. 倒装句

**全部倒装**（谓语全部在主语前）：
- There be句型
- Here/There/Now/Then + 谓语 + 名词主语
- 方位副词在句首

**部分倒装**（助动词/情态动词在主语前）：
- 否定词在句首：Never, Hardly, Seldom, Not until, No sooner...than
- Only + 状语在句首
- So/Such...that结构中so/such在句首
- 虚拟条件句省略if

### 2. 强调句

**结构**：It is/was + 被强调部分 + that/who + 其余部分

判断方法：去掉It is/was...that/who后句子仍完整

### 3. 省略句

- 状语从句中的主语和be动词省略
- 不定式符号to后内容的省略
- 定语从句中关系词的省略

### 3. 讲解的概念

| 概念 | 教学方法 | 理解程度 |
| --- | --- | --- |
| 形式主语 vs 形式宾语复习 | 用一个句子同时检查 `find it useful...` 与 `it is easier to...` | ✅好，选项正确；理由由老师补全 |
| `although/though` 让步状语从句 | 用“虽然……仍然……”语境判断前后逻辑 | ✅好 |
| `although` 与 `but` 不连用 | 通过改错题删除多余 `but` | ✅好 |
| `so...that...` 结果状语从句 | 通过语法填空和句子合并训练“如此……以至于……” | ✅好 |
| `such...that...` 结果状语从句 | 对比 `so + adj.` 与 `such + 名词短语` | ✅好 |
| 不可数名词前不用 `a` | 用 `advice` 检查 `such` 与 `such a` | ✅好 |

### 4. 理解检查回答

- 学生第1题选择 A 正确；老师补充：第一个 `it` 是形式宾语，真正宾语是 `to review new words in real contexts`；第二个 `it` 是形式主语，真正主语是 `to remember words when they are used...`。
- 学生能判断 `Although it was raining heavily...` 为让步/转折关系。
- 学生能改错：`Although he was very tired, he kept working until midnight.`
- 学生能判断考试难但仍不放弃应使用 `Although`，并能理解不是 `Because`。
- 学生能改写：`Although the task was hard, she finished it by herself.`
- 第6题 `I wanted to join..., ______ I was afraid...` 中学生选 `although` 并说明转折；老师指出该题有歧义，`but` 更自然，`although` 也可成立。
- 学生能改错：`Although I was nervous, I still gave the speech in front of the class.`
- 学生能判断 `so difficult that...`。
- 学生能合并：`The speech was so moving that everyone was deeply touched.`
- 学生能判断 `such a useful book that...`。
- 学生能改写：`The English class was so interesting that Niki wanted to speak more English after class.`
- 学生能复述规则：`such a + adj. + 单数名词 + that`；`so + adj./adv. + that`。
- 学生能输出：`The test was so difficult that many students failed the exam.`，老师建议更自然写作可改为 `failed it`。
- 学生能判断 `such useful advice that...`，并说明 `advice` 是不可数名词，不能用 `such a`。

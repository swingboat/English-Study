## 词汇学习方法

### 1. 词根词缀记忆法

**常见词根**：
| 词根 | 含义 | 例词 |
|------|------|------|
| -spect- | 看 | inspect, respect, aspect |
| -dict- | 说 | predict, dictionary, contradict |
| -port- | 携带 | import, export, transport |
| -duct- | 引导 | conduct, produce, introduce |
| -mit-/-miss- | 送 | permit, submit, dismiss |
| -scrib-/-script- | 写 | describe, prescription |
| -vert-/-vers- | 转 | convert, reverse, diverse |
| -tract- | 拉 | attract, extract, contract |

**常见前缀**：
| 前缀 | 含义 | 例词 |
|------|------|------|
| pre- | 在...之前 | preview, predict, prepare |
| re- | 再次/返回 | return, review, repeat |
| un- | 不/相反 | unhappy, unable, unfair |
| dis- | 不/相反 | disagree, disappear, discover |
| in-/im-/il-/ir- | 不 | impossible, illegal, irregular |
| ex- | 出/外 | export, exit, exceed |
| inter- | 在...之间 | international, internet |
| trans- | 跨越 | transport, transform |

**常见后缀**：
| 后缀 | 词性 | 例词 |
|------|------|------|
| -tion/-sion | 名词 | education, decision |
| -ment | 名词 | development, agreement |
| -ness | 名词 | happiness, kindness |
| -er/-or | 名词（人） | teacher, actor |
| -ful | 形容词 | helpful, beautiful |
| -less | 形容词（无） | helpless, careless |
| -able/-ible | 形容词（能） | available, possible |
| -ly | 副词 | quickly, carefully |

### 2. 语境记忆法

每个单词配合：
- 至少一个例句
- 常见搭配
- 高考真题例句（如有）

### 3. 词族记忆法

记单词时同时记忆其词族：
- succeed (v.) → success (n.) → successful (adj.) → successfully (adv.)
